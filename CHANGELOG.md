# Changelog

## 2.0.0 (unreleased)

- Redesigned the launcher with clearer prompts, helpful status messages, and a simpler command-line interface.
- Added an interactive account manager with optional aliases, auto-launch, and secure password saving.
- Added multi-Toon launching: select several saved accounts and open a game window for each.
- Added an optional first-time account setup wizard; explicit `--username` logins skip it.
- Added play-cookie sign-in using `--ask-play-cookie`, or provide either session value directly.
- Improved game updates with concurrent downloads and file integrity checks.
- Improved ToonGuard/2FA handling and error messages.
- Added automatic migration of launcher settings from version 1.4.
- Added automated tests and continuous integration for Windows, macOS, and Linux.
- Requires Python 3.11 or newer.
